# real_old/

Ground-truth'u olmayan **gerçek** eski fotoğraf ve videolarınızı buraya koyun (ör. aile albümü taramaları,
Library of Congress / Wikimedia Commons'taki kamu malı arşiv fotoğrafları).
Web arayüzündeki **Veri Seti** sekmesinde otomatik listelenir; GT olmadığı için referanssız ölçüler
(keskinlik, gürültü σ, renk zenginliği) ve görsel karşılaştırma kullanılır.
